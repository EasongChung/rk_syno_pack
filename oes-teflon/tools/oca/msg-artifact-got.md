### 我要和你定一个明确协议，避免再发生

**从今往后，你派完 CI 且尚未拿到结果时，消息末尾必须带一行醒目的「叫醒契约」**，格式固定：

```
【等 CI】run=<run_id>  预计=<分钟>  叫醒方式=<我该发什么消息给你>
```

例子：

```
【等 CI】run=39211898461  预计=3min  叫醒方式=发「CI 完了，取产物」给我
```

**理由**：你不写这句，我这边看到 IDLE 就会以为「它在等我下一步指令」，
而不是「它在等 CI，我得回头叫它」。**这一句是把「我等你」变成「我知道该回来叫你」。**

如果你判断 CI 会很快（<2min），也可以选择不退出一轮 —— 那是更好的，
但不要把「快速轮询」当作常规手段。
